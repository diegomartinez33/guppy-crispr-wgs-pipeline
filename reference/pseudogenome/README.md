# Colombian Guppy (*Poecilia reticulata*) Pseudogenome

**Status:** Production-ready. Suitable for read mapping, variant calling,
and CRISPResso2 analysis against the Colombian population background.

**Author:** da.martinez33 | Universidad de los Andes (Colombia)
**Date built:** July 2026
**Contact:** diegoandres3322@gmail.com

---

## What this is

A population-specific genome for the Colombian *Poecilia reticulata* (guppy)
population, built by applying high-confidence variants from the Control group
onto the Trinidad/Guanapo reference genome (GCF_000633615.1). The result is
a single-copy linear genome that reflects the majority allele at every
position where the Colombian population diverges from the reference.

This is one of **two** Colombian-population genome resources in this project —
they are complementary, not interchangeable:

| | This genome | `reference/colombian_scaffolded_genome/` |
|---|---|---|
| Method | Reference + majority-allele SNP/indel substitution (bcftools consensus) | *De novo* co-assembly + reference-guided scaffolding |
| Captures structural variants? | No — point substitutions and short indels only | Yes (in principle) |
| Coordinate system | Near-identical to Trinidad reference (use chain file for exact mapping) | Own coordinate system (`_RagTag` suffix) |
| Base-level accuracy | Very high — derived mathematically from variant calls | Draft quality — assembly errors possible |
| Recommended for | Read mapping, variant calling, CRISPResso2, IGV visualization | Structural analysis, novel sequence exploration |

If you need chromosome-scale structural information or novel sequence not
present in the Trinidad reference, use the scaffolded genome instead.
Use **this** genome for anything requiring precise coordinates or high
base-level accuracy.

## How it was built

**Tool:** `bcftools consensus` applied to the Trinidad reference genome.

| Step | What was done |
|---|---|
| 1. Variant calling | GATK HaplotypeCaller → GenotypeGVCFs on all 15 samples (2×150bp Illumina NovaSeq X, trimmomatic-trimmed) |
| 2. Variant filtering | GATK VariantFiltration (hard filters): SNPs QD<2/FS>60/MQ<40; INDELs QD<2/FS>200 |
| 3. Control subset | Selected PASS variants present in all 3 Control replicates at AF ≥ 0.667 |
| 4. Consensus generation | `bcftools consensus` applied Control SNPs + INDELs to GCF_000633615.1 reference |
| 5. Annotation | Liftoff v1.5.1 transferred Trinidad RefSeq gene models onto pseudogenome coordinates |

Input samples for variant selection: Control_MNP_I_S54_L002,
Control_MNP_II_S55_L002, Control_MNP_III_S56_L002.

The `colombian_pseudogenome.chain` file (generated by bcftools consensus)
maps every position in the Trinidad reference to the corresponding position
in this pseudogenome — use it for exact coordinate liftover with CrossMap.

## Quality summary

**Genome integrity:**
- Same contig count and structure as the Trinidad reference (2,768 contigs)
- Net size difference reflects the sum of inserted minus deleted bases from
  applied INDELs (slightly larger than reference)
- 12/12 automated verification checks passed (verify_pseudogenome.sh, Jul 15 2026)

**Annotation (Liftoff v1.5.1):**
- Transfer rate: **99.5%** (1,287,616 / 1,293,974 features transferred)
- Genes transferred: **26,264** with complete parent-child hierarchy
- 0 orphaned gene records (every gene has properly linked mRNA → exon/CDS)
- *bdnf* (target gene): NC_024333.1:15923726–15938393 (− strand),
  8 mRNA isoforms, 22 exons — confirmed present and correctly structured

## Limitations — read before using or sharing further

1. **Does not capture structural variants.** bcftools consensus applies only
   SNPs and short INDELs; large deletions, inversions, duplications, or
   sequence novel to the Colombian population (absent from the Trinidad
   reference) are not represented. Use the scaffolded genome
   (`reference/colombian_scaffolded_genome/`) if you need SVs.

2. **Represents the majority allele only.** Variants were included at
   AF ≥ 0.667 across the 3 Control individuals. Positions with lower
   frequency or heterozygous-only variants are left as the Trinidad
   reference allele. This is a single-haplotype consensus, not a phased
   diploid genome.

3. **Coordinates are close to, but not identical with, the Trinidad
   reference.** Every applied INDEL shifts all downstream coordinates by
   its net length. For analyses that mix coordinates from this pseudogenome
   with coordinates from the Trinidad reference (e.g., comparing VCF
   positions), always use the `.chain` file for conversion. Never assume
   positions are identical at regions downstream of any INDEL.

4. **Built from Control samples only.** Variants specific to the CRISPR
   treatment groups (RNP_Cas, Plasmid_Ko, Only_MNP) were deliberately
   excluded. This genome represents the unedited Colombian population
   background, not the full experimental diversity.

5. **Annotation confidence varies.** Liftoff transferred 99.5% of features
   from the Trinidad RefSeq annotation. The remaining 0.5% of features
   could not be mapped and are absent. Genes in regions with many dense
   INDELs may have slightly shifted exon boundaries. The *bdnf* locus has
   been individually verified; other loci have not been checked gene by gene.

6. **`colombian_pseudogenome.gff3` (CrossMap output) is superseded.**
   An earlier annotation attempt with CrossMap produced 64% of genes with
   broken parent-child hierarchy (gene/mRNA records missing while exons
   were present). That file is retained as a reference backup but should
   not be used for new analyses — use `.liftoff.gff3` instead.

## Quick start

**Map reads against this genome:**
```bash
module load bwa/0.7.17 samtools/1.16.1
bwa mem -t 8 colombian_pseudogenome.fna R1.fastq.gz R2.fastq.gz \
    | samtools sort -o output.sorted.bam
samtools index output.sorted.bam
```

**Extract a region:**
```bash
module load samtools/1.16.1
samtools faidx colombian_pseudogenome.fna "NC_024333.1:15923726-15938393"
```

**BLAST a sequence:**
```bash
module load blast/2.14.1+
blastn -db blast_db/colombian_pseudo -query query.fa \
    -outfmt "6 qseqid sseqid pident length evalue bitscore sstart send" \
    -perc_identity 90
```

**Find a gene in the annotation:**
```bash
grep "gene=bdnf" colombian_pseudogenome.liftoff.gff3 | awk '$3=="gene"'
```

**Convert coordinates from Trinidad reference to pseudogenome:**
```bash
# Requires CrossMap in crossmap_env (miniconda3_crispresso)
CrossMap bed colombian_pseudogenome.chain your_regions.bed output_regions.bed
```
