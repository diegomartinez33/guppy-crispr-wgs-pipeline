Method

1) bedtools makewindows -w 10000 -s 2000 over the whole genome. 2) Count of PASS SNPs/INDELs per window (bedtools coverage -counts). 3) Density = variants/kb; Z-score computed per chromosome (not genome-wide, to avoid bias from size/coverage differences between chromosomes). 4) Window = hotspot if its Z-score-associated p-value survives Benjamini-Hochberg correction with FDR<0.05 (fallback threshold Z>4.0 if statsmodels is unavailable). 5) Adjacent hotspot windows are merged (bedtools merge -d 2000) into the 403 final regions. 6) Gene annotation via direct overlap with the reference GFF; zebrafish orthologs via ID mapping + functional enrichment with gProfiler.
